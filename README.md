# Aurelia Fashion Store

Responsive women's fashion e-commerce landing page inspired by the supplied reference design, with a different brand identity, copy and image set.

## Tech
- React
- Vite
- CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Deploy to Vercel

Push the project to GitHub, then import the repository into Vercel.

Framework preset: **Vite**
Build command: `npm run build`
Output directory: `dist`

No environment variables are required.
