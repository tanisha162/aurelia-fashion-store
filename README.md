## 📌 Project Overview
**Aurelia** is a modern, responsive fashion retail web application showcasing elegant apparel catalogs, dynamic price and size filtering, persistent local storage cart management, and seamless mobile checkout interfaces.

---

## ✨ Features
- **Fluid Mobile-First Responsive Design:** Seamlessly adapts across smartphones, tablets, and high-resolution desktops.
- **Dynamic Shopping Cart:** Add, remove, and update quantities with real-time subtotal and tax calculation stored in `localStorage`.
- **Category & Price Filtering:** Instant client-side search and filtering without page reloads.
- **Fast Vite Bundling:** Lightning-fast HMR and optimized production asset minification.

## 🚀 Running Locally

cd aurelia-fashion-store

npm install
